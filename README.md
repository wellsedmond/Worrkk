# UPYR RUN — Ночь у арены

Существующий Canvas 2D-платформер переоформлен в мультяшную готику. Персонаж, размеры уровня, управление и физика сохранены. Внешних npm-зависимостей для игры нет.

![UPYR RUN — игровой экран](docs/upyr-run.png)

## Запуск на Windows без установки программ

Скачайте ZIP репозитория, распакуйте его и откройте **Worrkk.html** двойным щелчком. Это автономная сборка UPYR RUN со всей графикой внутри, без сетевых запросов. Открывать index.html через file:// не нужно.

## Разработка и Telegram Mini App

Нужен Node.js 20+:

```sh
npm start
```

Сервер слушает порт 3000 (или `PORT`). Откройте http://localhost:3000. Для Telegram разместите проект на HTTPS-хостинге: нужны index.html, style.css, atmosphere.js, game.js и вся папка assets. В BotFather укажите HTTPS-адрес как URL Mini App / кнопки меню. Hosted-версия сохраняет Telegram.WebApp.ready() и expand(). Автономная версия SDK Telegram не загружает.

Стрелки или A/D — движение, пробел/W/↑ — прыжок. На телефоне — экранные кнопки. Прыжок сверху уничтожает чеснок. Три жизни, монеты, флаг и перезапуск работают по прежним правилам.

## Устройство проекта

- `game.js`: единственная игровая сцена; исходные массивы платформ, враги, физика, камера, управление и загрузка героя/чеснока. Добавлены только вызовы визуальных эффектов и новой отрисовки.
- `atmosphere.js`: пять скоростей параллакса; красная луна, звёзды, облака, мыши, дальняя молния, свет фонарей и свечей, пыль, туман и осколки чеснока. SVG и каменная кладка растеризуются один раз. Невидимые платформы и декорации пропускаются; одновременно не более 90 частиц. Шейдеров, фильтров размытия и библиотек рендеринга нет.
- `assets/environment/`: самостоятельные SVG дворца-арены, готического горизонта, кладбищенского декора и паутины. СКА Арена изображена как стилизованная овальная чаша с ребристым фасадом и готическими башнями.
- `assets/hero.png`, `assets/garlic.svg`: прежние ассеты, без изменений.
- `index.html`, `style.css`: меню, сердца с клыками, счётчики, экран «ВАМПИР ПАЛ!» и сенсорные кнопки.
- `scripts/build-standalone.js`: сборка автономного Worrkk.html из действующих исходников. Редактируйте исходники, затем пересобирайте HTML.

В исходной версии один уровень. Звуковой системы, отдельной кнопки атаки, усилений, серверной авторизации, API, таблицы лидеров и постоянного сохранения нет. Новые механики, звук и сетевые сервисы в этой визуальной переработке не добавлялись. Свечение глаз по усилению не подключено, поскольку события усиления нет.

## Сборка и проверки

```sh
npm run check
npm test
npm run build
```

Пять Node-тестов проверяют прежние коллайдеры, прыжок и бег, монеты, урон, неуязвимость, уничтожение чеснока, проигрыш, победу, перезапуск, потолки и камеру.

Дополнительно выполнен `tests/browser-check.cjs` с Chromium / Playwright Core. Проверены HTTP-ресурсы и порядок загрузки скриптов, полный маршрут до победы, клавиатура, сенсорные кнопки, экран 390 × 844, отсутствие ошибок страницы, автономная работа без сети. Вызовы Telegram проверены с подставным SDK: это не проверка реального Telegram-клиента.

Для повторения браузерной проверки на Linux установите Chromium и Playwright Core вне checkout:

```sh
npm install --prefix /tmp/upyr-qa playwright-core --no-audit --no-fund
NODE_PATH=/tmp/upyr-qa/node_modules UPYR_CHROMIUM=/usr/bin/chromium node tests/browser-check.cjs
```

Скрипт сам запускает и останавливает тестовый сервер на порту 3137. Снимки пишет в `/tmp/upyr-*.png`; проверяет автономный файл после `npm run build`. В headless Chromium с четырёхкратным замедлением CPU медиана интервала кадров составила 33,3 мс, 95-й процентиль — 50 мс (около 20–30 FPS). Синхронные серии draw() давали редкие длинные задержки, поэтому их показатели не считаются игровым FPS. Измерения в headless Chromium не гарантируют FPS на телефонах.

## Оставшаяся художественная и аппаратная проверка

- Для точного архитектурного сходства СКА Арены нужна ручная сверка SVG с выбранным ракурсом реального здания: сейчас это художественная стилизация.
- Герой использует прежнее покачивание одного спрайта. Для покадрового бега, атаки и смерти понадобятся отдельные нарисованные кадры; текущие анимации не заменялись.
- Требуется проверка в реальном Telegram на Android и iOS, в том числе плавности на слабом устройстве. Авторизация, лидеры и сохранения не заявляются как реализованные.
