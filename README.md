# UPYR RUN — Level 1

**Проклятая дорога к СКА Арене** — первый уровень существующего Canvas 2D-платформера. Движок, PNG героя, базовая скорость 245 px/s, прыжок 590 px/s, гравитация 1550 px/s² и Telegram `ready()/expand()` сохранены. Симуляция работает фиксированными шагами 1/120 с, независимо от частоты отрисовки.

![Пробуждение Упыря](docs/upyr-run.png)

## Запуск на Windows

1. На GitHub нажмите **Code → Download ZIP**.
2. Распакуйте архив.
3. Откройте **Worrkk.html** двойным щелчком. Это автономная версия со встроенными изображениями, без установки Node.js и без запросов в сеть.

Для разработки с Node.js 20+:

```sh
npm start
```

Откройте http://localhost:3000. Порт можно задать переменной `PORT`. Для Telegram нужен HTTPS-хостинг всех исходных JS/CSS-файлов и папки `assets`, затем URL в BotFather. Открывать исходный index.html через file:// не нужно.

## Управление

| Действие | Клавиатура | Телефон |
| --- | --- | --- |
| Движение | ← → / A D | Стрелки |
| Прыжок | Пробел / ↑ / W | Прыжок |
| Удар | X / J | Удар |
| Приседание | ↓ / S | Удерживать «Присесть» |
| Пауза | Escape или кнопка | Кнопка «Пауза» |

Удар требует отдельного нажатия, откат — 0,42 с. При приседании рост хитбокса уменьшается с 80 до 44 px; ноги остаются на той же поверхности. Сквозь парящие платформы можно прыгать снизу и проходить сбоку; приземление происходит ногами при падении. Ярусы выше друг друга на 90 px. Звук выключен по умолчанию; включается отдельной кнопкой после жеста пользователя, настройка сохраняется.

Маршрут имеет длину 60 300 px. Автоматизированное прохождение обычными входными командами занимает около **5:12 вместе с финальной сценой**; оно собирает все три клыка и не использует продолжения. Это ориентир, а не обязательный таймер всего уровня. Босс после трёх выстрелов открывает шестисекундное окно для удара; ярость не позволяет снять больше одной жизни за окно.

## Контрольные точки, бонусы и сохранения

Контрольные точки действуют только в текущем забеге. На экране поражения можно продолжить у последнего активированного гроба с тремя жизнями или начать заново. Снимок восстанавливает собранные предметы, счёт, разрушенные стены и побеждённых врагов на момент активации. Это предотвращает повторное накопление очков на одних предметах. Время и полученный за весь забег урон не откатываются.

Кровавая ярость длится 10 с, усиливает удар по шлемам и стене, добавляет свечение глаз и частиц. Достижение «НЕПРОКУСИМЫЙ» выдаётся при завершении без урона, включая падения, истечение таймеров и неудачные попытки до продолжения.

`progress.js` хранит в localStorage факт завершения, лучшее время до завершения боя с боссом, максимум собранных клыков за забег, достижения и максимальный результат. Сохранение переживает перезагрузку страницы. При запрете хранилища игра продолжает работать и сообщает о невозможности сохранения.

**Это локальные, не проверенные сервером данные.** Серверной авторизации, API сохранений и таблицы лидеров в исходном проекте не было; они не имитируются. Локальный рекорд нельзя считать доказанным онлайн-результатом. Для рейтинга необходим отдельный сервер с проверкой Telegram initData и игрового результата. В автономном HTML хранилище зависит от браузера и пути к файлу; перенос файла может создать отдельное хранилище.

## Файлы и архитектура

- `game.js` — прежний игровой цикл и Canvas-отрисовка, расширенные ударом, приседанием, объектами уровня, контрольными точками, боссом и финальной сценой.
- `level1.js` — конфигурация пяти зон, платформ, врагов, ловушек, коллекционных предметов, контрольных точек, рычага, ворот и таймеров.
- `atmosphere.js` — существующий параллакс и эффекты; добавлены повторение на длинной карте, отсечение невидимых объектов, общие кэшированные текстуры и движение платформ.
- `level-art.js`, `assets/level1/` — графика новых объектов, различия зон, интерьер башни, эффекты удара, ярости и кат-сцены.
- `progress.js` — независимое от контрольных точек постоянное локальное сохранение.
- `sound.js` — синтезированная аркадная мелодия, шаги, удар и получение урона. AudioContext не создаётся до разрешённого взаимодействия.
- `index.html`, `style.css` — интерфейс и управление, включая одновременные касания.
- `scripts/build-standalone.js` — встраивание действующих исходников и графики в Worrkk.html.
- `tests/` — модульные проверки, тестовый водитель реального ввода и браузерная проверка.

Новое представление уровня добавлено к текущей сцене без стороннего движка. Герой `assets/hero.png` и чеснок `assets/garlic.svg` оставлены без изменений. Второй уровень пока не реализован; неработающей кнопки перехода нет.

## Сборка и тестирование

```sh
npm run check
npm test
npm run build
```

`npm test` выполняет 14 проверок: карту, односторонние коллизии, прыжок при 30/60/120 Гц, приседание, движущиеся и разрушающиеся платформы, удар/ярость, ловушки, клыки, контрольные точки, рычаг, фазы босса, локальное сохранение, паузу и полный маршрут до финала.

Для браузерной проверки на Linux нужны Chromium и Playwright Core вне checkout:

```sh
npm install --prefix /tmp/upyr-qa playwright-core --no-audit --no-fund
NODE_PATH=/tmp/upyr-qa/node_modules UPYR_CHROMIUM=/usr/bin/chromium node tests/browser-check.cjs
```

Тест сам запускает сервер на 3137 и останавливает его. Проверяет полное прохождение, три клыка, босса и кат-сцену, сохранение после перезагрузки, восстановление у гроба, одновременные касания, паузу, отсутствие звука до жеста, офлайн-сборку и постоянство количества объектов после 12 перезапусков. Снимки пишет в `/tmp/upyr-level1-*.png`.

Вызовы Telegram проверены с подставным SDK. Реальный клиент Telegram, авторизация и физические Android/iOS-устройства не тестировались. В headless Chromium на экране 390 × 844 измерены интервалы кадров около 16,7 мс в лесу, на кладбище, в башне и у босса; это не гарантия 60 FPS на телефоне. Требуется аппаратная проверка.

## Временные ассеты и оставшаяся художественная работа

Технически рабочие, но предварительные SVG: `helmet.svg`, `hunter.svg`, `coffin.svg`, `fang.svg`, `stake.svg`, `gate.svg`, `werewolf.svg`, `tower.svg`. Их следует заменить или доработать для финального релиза, особенно покадровые атаки/поражение охотника и шлема. Герой сохраняет исходное покачивание спрайта; приседание и жест поправления кепки сделаны трансформацией и рисованным эффектом руки. Для полноценных анимаций нужны отдельные нарисованные кадры.

Нужна ручная сверка дворца-арены с фотографическим ракурсом СКА Арены. Синтезированный звук — временное оформление, для релиза нужны музыкальная дорожка и качественные записи ветра, огня, грома и крыльев.
