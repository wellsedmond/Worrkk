# Кепка: большой забег

Прототип платформера для Telegram Mini App на HTML Canvas без npm-зависимостей.
Герой — детализированный PNG-спрайт, созданный по референсу. Враги — зубчики чеснока в SVG. Плавное покачивание спрайта при движении; покадровая анимация ходьбы пока не добавлена.

## Запуск

Нужен Node.js 20+.

```sh
cd /workspace/Worrkk
npm start
```

Порт по умолчанию — 3000; можно задать `PORT`. `npm run check` проверяет синтаксис.
Стрелки или A/D — движение, пробел/W/↑ — прыжок. На телефоне используются экранные кнопки.
Собирайте монеты, прыгайте на врагов и доберитесь до флага. Пропасть завершает забег.

## Telegram

Разместите index.html, style.css и game.js на HTTPS-хостинге (в корне сайта)
или запустите Node-сервер за HTTPS reverse proxy. В BotFather укажите HTTPS-адрес
как URL Mini App / кнопки меню вашего бота. Токен бота для самой игры не нужен.
Интеграция вызывает Telegram.WebApp.ready() и expand(); игра работает и вне Telegram.

Это локальная игра: серверной проверки очков, таблицы лидеров и сохранения прогресса пока нет.
Проверены синтаксис и Chromium: загрузка графики, приземление, прыжок, монеты, падение, финиш, защита после урона и прыжок на чеснок. Кириллица проверена на снимке экрана. Telegram на телефоне требует отдельной проверки перед публикацией.

Worrkk.html — автономная версия со встроенными стилями, кодом и графикой; открывается без Node.js и сети. Изменения исходных файлов автоматически в неё не попадают.
