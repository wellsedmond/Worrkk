# Публикация Telegram Mini App

Используйте последнюю ветку `fix/smooth-hero-latest`. `main` пока содержит старую версию игры.

## Сервер

Игра запускается командой `npm start` на Node.js 22. Хостинг должен предоставлять HTTPS, один процесс приложения и постоянный диск. Сервер отдаёт `index.html`, JS/CSS, изображения, музыку и `/api/achievements` с одного домена.

На существующем хостинге выберите нужную ветку репозитория `wellsedmond/Worrkk`, команду запуска `npm start` и задайте:

- `TELEGRAM_BOT_TOKEN`: токен нужного бота из BotFather, только на сервере.
- `UPYR_DATA_DIR`: каталог на постоянном диске, доступный для записи.
- `PORT`: порт, назначенный хостингом.

Не размещайте проект только как статический сайт: серверная синхронизация достижений требует Node.js. Не используйте автономный `Worrkk.html` как адрес Mini App: он предназначен для офлайн-проверки и не подключает Telegram SDK.

## Подключение бота

Бот игры: @UpyrPlatformer_game. После проверки рабочего HTTPS-адреса откройте @BotFather:

1. `/mybots` → нужный бот → Bot Settings → Configure Mini App. Задайте URL корня опубликованного сервиса как Main Mini App.
2. Настройте Menu Button для того же бота: название «Играть», URL того же сервиса. Можно использовать команду `/setmenubutton`.
3. Откройте личный чат с ботом и нажмите кнопку запуска игры.

Названия пунктов BotFather могут отличаться в зависимости от клиента. После настройки основного Mini App ссылка запуска: `https://t.me/UpyrPlatformer_game?startapp`.

## Проверка после публикации

- Внутри Telegram открывается последняя версия, доступны бег, прыжок, удар и приседание.
- Достижения показывают успешную серверную синхронизацию; после повторного открытия профиль восстанавливается.
- Звук включается пользовательским нажатием, управление работает на телефоне.
- Запуск через обычный браузер использует отдельный гостевой профиль.
- Перезапуск сервиса сохраняет данные на постоянном диске. Настройте резервные копии диска средствами выбранного хостинга.

Публикация считается завершённой только после получения HTTPS-адреса, настройки бота и проверки реального запуска в Telegram.

## Приветствие бота

`telegram-bot.js` запускается отдельным процессом `node telegram-bot.js`. Он отвечает на `/start` в личном чате приветствием и кнопкой «Играть» с типом `web_app`. Использует `TELEGRAM_BOT_TOKEN`, `TELEGRAM_GAME_URL` (по умолчанию `https://game.46-17-97-222.sslip.io/`) и `UPYR_BOT_DATA_DIR` (по умолчанию `/data/bot`) на постоянном диске для позиции обработанных сообщений.

Для одного токена запускайте только один обработчик. Существующий webhook автоматически не удаляется. Токен берётся из защищённого файла окружения на сервере; его не нужно вводить повторно или размещать в клиентских файлах. Контейнер приветствия можно перезапускать отдельно от игры.

## Рейтинг игроков

В главном меню доступен «Рейтинг игроков»: топ-50 по накопленным монетам за все игры, собственное место показывается и за пределами топа. Одинаковое число монет даёт одинаковое место. Учитываются монеты существующего серверного журнала `stats.coins`, включая игровые награды; текущий счёт забега и очки достижений не подменяют эту сумму.

`POST /api/leaderboard` принимает подписанный Telegram `initData`. Он читает сохранённые профили из той же `UPYR_DATA_DIR`, не принимает готовые суммы монет от клиента и не возвращает ID аккаунтов. Имя обновляется из подписанного профиля Telegram при синхронизации достижений. Старые профили сохраняют накопленные монеты, а до следующей синхронизации могут отображаться как «Игрок».

Профили остаются на существующем постоянном диске. Отдельная база или новый токен не нужны. В автономном файле и гостевом браузере показана подсказка открыть Telegram; вымышленного общего рейтинга нет. Достоверность суммы имеет те же ограничения, что и существующий журнал игровых событий: сервер проверяет аккаунт и повторные события, но не воспроизводит физику игры.

Проверки: `node --test tests/leaderboard.test.js`, `node tests/leaderboard-browser.cjs`.
